# Chapter 1 Question Blueprint — Certification of OTR

## Purpose
Guide the Question Maker when generating original practice items for Chapter 1. This blueprint uses the study team's chapter map and does not reproduce textbook content.

## Target topics
- NBCOT certification versus state licensure
- Regulatory boards and licensure compact
- Exam content and four-domain structure
- Exam format and item development
- Application process
- Testing accommodations
- Exam-day considerations
- Test-taking strategies
- Post-exam considerations

## Question design
- Use a realistic entry-level OT scenario.
- Prefer application or analysis questions.
- End the stem with a prioritization question.
- Require the student to distinguish between closely related actions, responsibilities, or processes.
- Use four plausible answer choices.
- Distractors should represent realistic reasoning errors.
- Do not use copied textbook or exam questions.
- Do not present generated items as actual NBCOT exam questions.

## Domain emphasis
- Favor Domain 4 when the scenario concerns certification, licensure, application, accommodations, or practice-management responsibilities.
- Use Domains 1–3 when the scenario genuinely tests evaluation, planning, or intervention decisions.
- Do not force a domain assignment when the topic does not support it.

## Bloom's level
Default to:
- Application
- Analysis

Occasionally use:
- Knowledge or comprehension for foundational terminology.
- Evaluation when several plausible actions must be compared.

## Scenario guidance
Good scenarios should provide enough information for the student to identify the relevant issue without relying entirely on outside knowledge.

Possible scenario frames:
- A student preparing for certification and asking about the distinction between certification and state licensure.
- An OT applicant working through an application or accommodation question.
- An entry-level OT considering a regulatory or practice-management responsibility.

## Quality check
Before returning an item, verify:
1. The question tests judgment rather than trivia.
2. There is one best answer.
3. All four options are plausible.
4. The stem contains enough information to support the decision.
5. The Bloom level matches the cognitive demand.
6. The selected domain matches the scenario.
7. The item is original practice material.
